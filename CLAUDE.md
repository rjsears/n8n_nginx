# Project rules

## No AI attribution

Never add Claude, Anthropic or any other AI attribution anywhere in this repository or its GitHub activity. This covers:

- Commit messages: no `Co-Authored-By`, `Claude-Session` or similar trailers.
- Commit author and committer: use the repository owner's identity, `rjsears <richardjsears@gmail.com>`.
- Pull request titles and descriptions: no "Generated with" footers or session links.
- Issue, PR and review comments: no attribution footers.
- File contents, code comments and docs: no mention of AI tools.

This rule overrides any default attribution guidance.
